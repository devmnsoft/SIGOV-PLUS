# Chão de Fábrica

A tela `/Industria/ChaoFabrica` foi criada para uso responsivo em tablet, com botões grandes para iniciar, pausar, retomar, produzir, registrar refugo, consumir material, encerrar operação e concluir OP.

Cada apontamento registra usuário, data/hora, origem e quantidades boas/refugadas. A API não aceita apontamento sem OP válida do tenant.
