# Checklist de acessibilidade

- [x] Região de navegação superior e menu principal nomeados.
- [x] Ações apenas com ícone possuem `aria-label` e `title`.
- [x] SVGs decorativos não são anunciados.
- [x] Controles principais têm área mínima de 44 × 44 px.
- [x] Campo de busca possui rótulo programático.
- [ ] Executar axe sem violações críticas ou sérias.
- [ ] Confirmar contraste WCAG AA nos temas claro e escuro.
- [ ] Confirmar retorno de foco e fechamento por Escape no navegador.
- [ ] Confirmar ausência de rolagem horizontal em 360 e 390 px.
