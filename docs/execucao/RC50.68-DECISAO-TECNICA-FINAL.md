## Como remover o bloqueio

1. Em máquina não produtiva, instalar exatamente o SDK de `global.json`, Node.js, PowerShell 7
   (para validar o caminho Windows) e cliente `psql`; disponibilizar PostgreSQL 16.x descartável.
2. Exportar apenas no processo as cinco variáveis `SIGOV_DB_*` descritas no roteiro de promoção.
   O host não pode conter marcador de produção, o nome do banco deve conter marcador seguro e o
   ambiente não pode ser `Production`.
3. Executar `./scripts/rc50-68-local-promotion.sh --confirm --smoke` ou a variante PowerShell.
   Para concluir o smoke autenticado, fornecer cookie efêmero local por
   `SIGOV_LOCAL_AUTH_COOKIE`; sem ele essa etapa permanece BLOCKED.
4. Confirmar exit code 0 e que cada item de `result.json` é PASS. Arquivar a evidência fora do Git
   conforme a política do operador; nunca copiar o log bruto, cookie, senha ou connection string.
5. Tratar o CI oficial separadamente. Um PASS local não declara automaticamente o gate oficial
   verde.

Qualquer FAIL ou BLOCKED mantém a promoção RC50.68 bloqueada e impede iniciar a RC50.69.
