# Entrega RC50.91 — Assistência Social360

- Modelo PostgreSQL idempotente para unidades, famílias, atendimentos, acompanhamento, vulnerabilidades, benefícios, programas, visitas, acolhimento, conselho tutelar, rede e auditoria.
- Rotas MVC do painel e áreas operacionais, com orientação de uso e aviso LGPD.
- Portal autenticado iniciado para dados próprios do cidadão.
- Permissões específicas cadastradas no catálogo e no banco.
- Integrações externas permanecem condicionadas a adaptadores e vínculos reais.
