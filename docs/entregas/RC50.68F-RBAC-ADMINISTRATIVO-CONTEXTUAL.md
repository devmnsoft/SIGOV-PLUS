# Entrega RC50.68F — RBAC administrativo contextual

## Jornadas cobertas

1. O SuperAdmin abre `/SaasAdmin/Autorizacao`; o avaliador persistente valida `administrar`.
2. Filtros por texto, tenant e estado carregam exclusivamente os catálogos e vínculos do banco.
3. Modais criam ou editam perfil, grupo, permissão e cada uma das três relações canônicas.
4. A matriz perfil-permissão grava recurso/ação por permissão e contexto, efeito, vigência, alçada,
   justificativa e estado no modelo consumido pelo avaliador RC50.68B.
5. Ativar, inativar e excluir logicamente retornam mensagens claras e geram auditoria transacional.

## Contratos e limites

- Application define DTOs e `IAuthorizationAdminService` sem dependência de persistência.
- Infrastructure implementa consultas e transações parametrizadas com Dapper/PostgreSQL.
- Web expõe endpoints protegidos por antiforgery e autorização persistida; JavaScript não decide
  autorização e não contém catálogos de autoridade.
- O PK composto legado dos vínculos é preservado; UUIDs não são convertidos e EF Core não é usado.
- A combinação perfil/permissão continua única conforme o schema existente; editar atualiza o
  contexto dessa combinação em vez de criar uma autoridade paralela.

## Aceite e gate externo

O fluxo elimina a necessidade de editar SQL manualmente para administrar a matriz. A homologação
dinâmica com .NET 10 e PostgreSQL 16 deve ocorrer no CI real. A RC50.68E-R4 segue **BLOCKED** por
autenticação externa ausente; este trabalho não consulta Actions, não exige URL de run, não valida
`SIGOV_CI_DB_PASSWORD` e não inicia RC50.69.
