# RC50.68D — Dashboard operacional SuperAdmin

## Matriz funcional

| Área | Fonte | Comportamento sem fonte |
|---|---|---|
| tenants, plano, módulos, domínios e contexto | tabelas canônicas `sigov` | dashboard indisponível se o núcleo não existe |
| decisões de autorização | `autorizacao_decisao_auditoria` | alerta `Indisponível` |
| trocas e negativas de contexto | `contexto_operacional_auditoria` | alerta `Indisponível` |
| auditoria | `auditoria` | estado vazio explícito |
| outbox | `outbox_evento` | `Não configurado` |
| webhook, worker e LGPD | tabelas opcionais detectadas | `Não configurado` |

## Controles

- filtros por tenant, período, módulo e status;
- refresh manual e links de operação;
- CSV protegido contra fórmula e JSON com o mesmo modelo minimizado;
- permissão `saas.superadmin.dashboard.visualizar` ou `exportar`, sempre avaliada no PostgreSQL;
- nenhuma coleção mock, dado pessoal completo ou segredo.

## Gates

Os comandos obrigatórios estão registrados no fechamento da implementação. Gates que dependem de
SDK, PowerShell, PostgreSQL, Docker, `actionlint` ou secret administrativo devem permanecer
**BLOCKED** quando o recurso não estiver disponível; não constituem PASS inferido.
