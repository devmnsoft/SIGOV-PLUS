## Sincronização SQL

Os 110 itens `includeInBaseline=true` foram compostos na ordem do manifest, com checksum SHA-256
validado para cada fonte. As quatro cópias de produção ficaram byte a byte iguais e as duas cópias
Development ficaram byte a byte iguais entre si, acrescidas somente dos seeds fictícios oficiais.
A verificação do gerador passou a abranger todas essas saídas para impedir novo drift.

O PostgreSQL não estava disponível; portanto sintaxe em servidor, idempotência, postconditions,
permissões SUPERADMIN e queries do dashboard são P1 **BLOCKED**, não PASS. Não foi criada migration
corretiva porque a correção foi apenas de empacotamento e não altera schema.
